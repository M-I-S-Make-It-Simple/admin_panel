# Адмін-панель для сайту школи

## Опис

Повноцінна адмін-панель для управління сайтом школи з 22 різними розділами. Система дозволяє адміністратору редагувати, додавати та видаляти контент на всіх сторінках сайту.

## Функціональність

### 1. Авторизація
- Система входу для адміністратора
- Захист всіх сторінок адмін-панелі
- Тільки авторизований користувач має доступ до редагування

### 2. Розділи сайту (22 розділи)

#### Основна інформація:
- **Наша візитка** - фото, текст, заголовки
- **Історія закладу** - фото, текст, заголовки  
- **Інноваційна діяльність** - фото, текст, заголовки

#### Новини та події:
- **Новини** - заголовок, текст, галерея фото
- **Інтелект та обдарованість** - заголовок, текст, галерея фото
- **Учнівське самоврядування** - заголовок, текст, галерея фото
- **Проєктно-дослідницька робота** - заголовок, текст, галерея фото
- **Національно-патріотичне виховання** - заголовок, текст, галерея фото
- **Критерії оцінювання** - предмети з посиланнями на критерії оцінювання
- **Клуби та студії** - заголовок, текст, галерея фото
- **СпортLife** - заголовок, текст, галерея фото

#### Педагогічний колектив:
- **Вчителі** - прізвище, ім'я, посада, опис, фото, категорія
- Сортування по категоріях: адміністрація, початкових класів, іноземних мов, тощо

#### Документи та звітність:
- **Нормативні документи** - заголовки, текст, посилання
- **Фінансова звітність** - заголовки, текст, посилання
- **Публічна інформація** - заголовки, текст, посилання

#### Підтримка та розвиток:
- **Соціально-психологічна підтримка** - заголовки, текст
- **Протидія булінгу** - заголовки, текст
- **На допомогу вчителю** - статтяи з заголовками, текстом, посиланнями
- **Підвищення кваліфікації** - статтяи з заголовками, текстом, посиланнями
- **Атестація педпрацівників** - статтяи з заголовками, фото, текстом, посиланнями
- **Основні методичні заходи** - статтяи з заголовками, фото, текстом

#### Для батьків та учнів:
- **Батькам** - текст, фото
- **Учням** - текст, фото

## Технології

- **Frontend**: Next.js 14, React, TypeScript
- **Backend**: Next.js API Routes
- **База даних**: PostgreSQL з Prisma ORM
- **Авторизація**: NextAuth.js
- **Стилізація**: Tailwind CSS, shadcn/ui
- **Завантаження файлів**: Cloudinary

## Налаштування

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Налаштування бази даних
```bash
# Створення міграції
npx prisma migrate dev --name init

# Генерація Prisma Client
npx prisma generate
```

### 3. Налаштування змінних середовища
Створіть файл `.env.local`:
```env
DATABASE_URL="postgresql://username:password@localhost:5432/school_db"
NEXTAUTH_SECRET="your-secret-key"
NEXTAUTH_URL="http://localhost:3000"
CLOUDINARY_CLOUD_NAME="your-cloudinary-cloud-name"
CLOUDINARY_API_KEY="your-cloudinary-api-key"
CLOUDINARY_API_SECRET="your-cloudinary-api-secret"
```

### 4. Запуск проекту
```bash
npm run dev
```

## Використання

### 1. Вхід в адмін-панель
- Перейдіть на `/login`
- Введіть логін та пароль адміністратора
- Після успішної авторизації ви будете перенаправлені в адмін-панель

### 2. Навігація
- Використовуйте сайдбар для навігації між розділами
- Розділи згруповані за категоріями для зручності

### 3. Редагування контенту

#### Для сторінок з текстом та фото:
1. Натисніть "Додати новий запис"
2. Заповніть заголовок та текст
3. Завантажте фото (опціонально)
4. Натисніть "Додати"

#### Для сторінок з новинами:
1. Натисніть "Додати новий запис"
2. Заповніть заголовок та текст
3. Завантажте кілька фото для галереї
4. Натисніть "Додати"

#### Для статтяів:
1. Натисніть "Додати новий стаття"
2. Заповніть заголовок та текст статтяа
3. Додайте посилання або фото (опціонально)
4. Використовуйте стрілки ↑↓ для зміни порядку
5. Натисніть "Додати"

#### Для вчителів:
1. Натисніть "Додати нового вчителя"
2. Заповніть ПІБ, посаду, опис
3. Виберіть категорію
4. Завантажте фото
5. Натисніть "Додати"

### 4. Редагування та видалення
- Кожен запис має кнопки "Редагувати" та "Видалити"
- При редагуванні форма заповниться поточними даними
- При видаленні з'явиться підтвердження

## Особливості

### 1. Завантаження файлів
- Підтримка завантаження зображень
- Автоматичне зменшення розміру
- Безпечне зберігання

### 2. Сортування
- Акордеони можна сортувати за допомогою стрілок
- Вчителі сортуються по категоріях
- Новини сортуються за датою публікації

### 3. Безпека
- Всі сторінки захищені авторизацією
- Валідація даних на сервері
- Безпечне зберігання паролів

### 4. Адаптивність
- Адмін-панель працює на всіх пристроях
- Зручний інтерфейс для мобільних пристроїв

## Розширення

### Додавання нового розділу:
1. Додайте модель в `prisma/schema.prisma`
2. Створіть API роути в `app/api/`
3. Створіть сторінку в `app/(admin)/`
4. Додайте посилання в `components/sidebar.tsx`

### Додавання нових типів контенту:
1. Створіть новий компонент в `components/`
2. Додайте відповідні API роути
3. Оновіть схему бази даних

## Підтримка

Для отримання допомоги або повідомлення про помилки:
1. Перевірте логи в консолі браузера
2. Перевірте логи сервера
3. Переконайтеся, що база даних працює коректно
4. Перевірте налаштування змінних середовища
