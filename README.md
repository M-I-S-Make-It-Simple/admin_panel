# Адмін-панель для сайту ліцею

Повноцінна адмін-панель для управління контентом сайту ліцею з 22 розділами. Система дозволяє адміністратору редагувати, додавати та видаляти контент на всіх сторінках сайту.

## 🚀 Швидкий старт

1. **Клонування репозиторію:**
   ```bash
   git clone <repository-url>
   cd admin_panel
   ```

2. **Встановлення залежностей:**
   ```bash
   npm install
   ```

3. **Налаштування бази даних:**
   ```bash
   npx prisma migrate dev
   npx prisma generate
   ```

4. **Запуск проекту:**
```bash
npm run dev
   ```

5. **Вхід в адмін-панель:**
   - Відкрийте: `http://localhost:3000/login`
   - Логін: `admin`
   - Пароль: `admin123`

## 🛠️ Технології

- **Frontend**: Next.js 14, React, TypeScript
- **Backend**: Next.js API Routes
- **База даних**: SQLite з Prisma ORM
- **Авторизація**: NextAuth.js
- **Стилізація**: Tailwind CSS, shadcn/ui
- **Завантаження файлів**: Cloudinary

## 🎯 Особливості

### Універсальні компоненти:
1. **AccordionManager** - для розділів з статтяами
2. **NewsManager** - для розділів з новинами та фото галереєю
3. **SimpleContentManager** - для простих сторінок з текстом та фото
4. **LinksManager** - для сторінок з посиланнями

### Функціональність:
- Автоматичне сортування статтяів
- Галерея фото для новин
- Завантаження зображень
- Редагування та видалення записів
- Адаптивний дизайн
- Захист авторизацією

## 🔧 Налаштування

```env
NEXTAUTH_SECRET=my-super-secret-key-for-school-admin-panel-2024
NEXTAUTH_URL=http://localhost:3000
DATABASE_URL="file:./dev.db"
```

### База даних
```bash
# Створення міграції
npx prisma migrate dev --name init

# Генерація Prisma Client
npx prisma generate
```

## 📖 Використання

### 1. Вхід в адмін-панель
- Перейдіть на `/login`
- Введіть логін та пароль адміністратора
- Після успішної авторизації ви будете перенаправлені в адмін-панель

### 2. Навігація
- Використовуйте сайдбар для навігації між розділами
- Розділи згруповані за категоріями для зручності

### 3. Редагування контенту

#### Для сторінок з текстом та фото:
1. Натисніть "Додати новий запис"
2. Заповніть заголовок та текст
3. Завантажте фото (опціонально)
4. Натисніть "Додати"

#### Для сторінок з новинами:
1. Натисніть "Додати новий запис"
2. Заповніть заголовок та текст
3. Завантажте кілька фото для галереї
4. Натисніть "Додати"

#### Для статтяів:
1. Натисніть "Додати новий стаття"
2. Заповніть заголовок та текст статтяа
3. Додайте посилання або фото (опціонально)
4. Використовуйте стрілки ↑↓ для зміни порядку
5. Натисніть "Додати"

#### Для критеріїв оцінювання:
1. Натисніть "Додати новий предмет"
2. Введіть назву предмету
3. Додайте посилання на критерії оцінювання
4. Використовуйте стрілки ↑↓ для зміни порядку
5. Натисніть "Тестувати посилання" для перевірки
6. Натисніть "Додати"

#### Для вчителів:
1. Натисніть "Додати нового вчителя"
2. Заповніть ПІБ, посаду, опис
3. Виберіть категорію
4. Завантажте фото
5. Натисніть "Додати"
