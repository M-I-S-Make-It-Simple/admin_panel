# Швидкий старт адмін-панелі

## 🚀 Запуск проекту

1. **Встановлення залежностей:**
   ```bash
   npm install
   ```

2. **Налаштування бази даних:**
   ```bash
   npx prisma migrate dev
   npx prisma generate
   ```

3. **Запуск сервера:**
   ```bash
   npm run dev
   ```

4. **Відкрийте браузер:**
   ```
   http://localhost:3000
   ```

## 🔐 Вхід в адмін-панель

1. Перейдіть на сторінку входу: `http://localhost:3000/login`
2. Використовуйте наступні дані:
   - **Логін:** `admin`
   - **Пароль:** `admin123`

## 🔧 Вирішення проблем

### Проблема з входом:
Якщо виникає проблема з Vercel при вході:
1. Перейдіть на `http://localhost:3000/clear-session`
2. Спробуйте увійти знову

### Налаштування завантаження файлів (Cloudinary):
Для завантаження файлів на хмарний сервер:

1. Зареєструйтесь на [Cloudinary](https://cloudinary.com/)
2. Отримайте ваші облікові дані з Dashboard
3. Додайте їх до `.env.local`:
```env
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-api-key
CLOUDINARY_API_SECRET=your-api-secret
```

**Примітка:** Якщо Cloudinary не налаштований, файли будуть завантажуватися локально.

### Проблеми з базою даних:
```bash
npx prisma migrate reset
npx prisma migrate dev
```

### Проблеми з залежностями:
```bash
rm -rf node_modules
npm install
```

## 📞 Підтримка

При виникненні проблем:
1. Перевірте логи в консолі браузера (F12)
2. Перевірте логи сервера в терміналі
3. Переконайтеся, що база даних працює коректно

## 🔒 Безпека

- Змініть пароль адміністратора в `app/api/auth/[...nextauth]/route.ts`
- Оновіть `NEXTAUTH_SECRET` в `.env.local` для продакшену
- Регулярно створюйте резервні копії бази даних

#### Для статтяів:
1. Натисніть "Додати новий стаття"
2. Заповніть заголовок та текст статтяа
3. Додайте посилання або фото (опціонально)
4. Використовуйте стрілки ↑↓ для зміни порядку
5. Натисніть "Додати"

#### Для критеріїв оцінювання:
1. Натисніть "Додати новий предмет"
2. Введіть назву предмету
3. Додайте посилання на критерії оцінювання
4. Використовуйте стрілки ↑↓ для зміни порядку
5. Натисніть "Тестувати посилання" для перевірки
6. Натисніть "Додати"

#### Для вчителів:
1. Натисніть "Додати нового вчителя"
2. Заповніть ПІБ, посаду, опис
3. Виберіть категорію
4. Завантажте фото
5. Натисніть "Додати"
